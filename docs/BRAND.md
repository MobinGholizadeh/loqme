## 3. Visual Identity & Palette Strategy

The visual atmosphere of Loqme is clean, fresh, modern, trustworthy, and calm: **White is the canvas. Teal is the identity.**

```
+-----------------------------------------------------------------------------+
|                                                                             |
|   Dark Turquoise / Teal     Deep Charcoal Slate  Restrained Emerald         |
|   #0F766E (Primary Brand)   #0F172A (Text)       #10B981 (Success/Safety)   |
|                                                                             |
|   Pure White Canvas         Subtle Neutral Tint  Muted Amber                |
|   #FFFFFF (Dominant 70-85%) #F8FAFC (Secondary)  #F59E0B (Warnings)         |
|                                                                             |
+-----------------------------------------------------------------------------+
```

### 3.1 Color Roles
* **Primary Brand / Action**: Dark Turquoise / Deep Teal / سبز کله‌غازی (`#0F766E`, `#115E59`, `#0D9488`). Communicates trust, freshness, quality, and modern technology. Used for primary CTAs, active navigation states, and brand accents.
* **Canvas Foundation**: Pure Clean White (`#FFFFFF`, dominant 70–85% of visual area) with very light neutral secondary surfaces (`#F8FAFC`). Creates an airy, spacious, modern canvas.
* **Typographic Anchor**: Deep Slate Charcoal (`#0F172A`, `#1E293B`). High-contrast, sharp, and comfortable to read.
* **Secondary Text**: Muted Slate Gray (`#475569`, `#64748B`).
* **Subtle Brand Tint**: Soft Teal (`#F0FDFA`, `#CCFBF1`) for selected states, cards, and soft badge backgrounds.
* **Semantic Accents**: Restrained Emerald (`#10B981`) for safety verified tags, Muted Amber (`#F59E0B`) for warnings, Crimson (`#EF4444`) for errors. Avoid orange as a major brand color.

### 3.2 Prohibited Visual Directions
* **No Generic Food Delivery Clone**: Avoid SnappFood-style magenta/red dominance or generic red banner ads.
* **No Environmental NGO Look**: Do not drape the entire interface in mossy green, leaf illustrations, or guilt-laden planetary graphics.
* **No Cheap Coupon Aggregator Look**: No chaotic dashed borders, flashing sale stickers, or noisy banner ads.
* **No Childish Gamification**: Avoid childish cartoon mascots or tacky scratch-off card animations.
* **Zero Proprietary Asset Theft**: Never copy or adapt proprietary iconography, banners, or design components from DigiKala, Snapp, or Divar.

## 4. Typography Standards

* **Default Font Family**: **Vazirmatn** (وزیرمتن)  
  * Licensed under Open Font License (OFL).
  * Highly legible, contemporary Persian typeface with comprehensive weight support.
* **Hierarchy Weights**:
  * **Headings (H1/H2)**: Bold / ExtraBold (700 / 800)
  * **Section Titles (H3/H4)**: SemiBold (600)
  * **Body & Descriptions**: Regular / Medium (400 / 500)
  * **Numbers & Pricing**: Medium / Bold (500 / 700) rendered with native Persian digits (`۰ ۱ ۲ ۳ ۴ ۵ ۶ ۷ ۸ ۹`).
* **Proprietary Font Policy**: Proprietary commercial fonts (e.g., IranSans, Shabnam, Dana) must not be bundled or committed without explicit commercial licensing documentation.

## 5. Voice & Tone Guide

| Context | Recommended Voice | What to Avoid |
| :--- | :--- | :--- |
| **Homepage Discovery** | *«امروز چه طعم تازه‌ای در محله شما منتظر کشف است؟»* | *«کمک کنید تا این غذاها دور ریخته نشوند.»* (Guilt) |
| **Surprise Bag Card** | *«بسته شگفت‌انگیز نان و شیرینی داغ با ۶۰٪ تخفیف واقعی»* | *«بسته ته‌مانده‌های شیرینی‌فروشی»* (Stigma) |
| **Pickup Confirmation** | *«لقمه شما آماده است! تا ساعت ۲۱:۴۵ به کافه روحی سر بزنید.»* | *«سفارش ضایعات تحویل شد.»* (Degrading) |
