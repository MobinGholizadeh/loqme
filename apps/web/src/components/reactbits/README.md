# React Bits Components

Animated components vendored from [React Bits](https://reactbits.dev) ([DavidHDev/react-bits](https://github.com/DavidHDev/react-bits)) under the MIT license, customized for Loqme's White + Teal design system, Persian RTL text, and accessibility.

## Components Included:
- `SplitText`: Smooth staggered text entrance powered by GSAP and `@gsap/react`.
- `SpotlightCard`: Interactive card with a soft radial spotlight that tracks cursor movement.
- `ShinyText`: Sweeping gradient sheen across text.
- `Magnet`: Magnetic cursor pull with smooth spring physics.
- `CountUp`: Number counter with Persian/Arabic digit and separator support.
