# Magic UI components

Vendored and adapted from https://github.com/magicuidesign/magicui/tree/main/apps/www/registry/magicui on 2026-10-14 under the accompanying MIT license.

Ripple Button, Blur Fade and Magic Card use Loqme tokens, the already installed framer-motion runtime, native button semantics and reduced-motion support. Ripple cleanup uses animation completion and bounds concurrent ripples. Blur Fade keeps server-rendered content visible and does not hide form controls behind scroll triggers. Magic Card uses a decorative pointer-inert gradient without wrapping or changing child layouts. No next-themes or second animation runtime is required.
